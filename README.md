# Rembry

Rembry 是一款本地优先的专业课主观题整理、背诵、抽查与学习计划工具。

此仓库只用于发布官方安装包和版本信息，不存放项目源代码。

## 下载

请从右侧或页面顶部的 Releases 下载最新版：

- Windows：`Rembry_*_windows_x64_setup.exe`
- Android：`Rembry_*_android.apk`

## 数据说明

- Rembry 当前以本地离线使用为主，电脑和手机的数据彼此独立。
- 正常覆盖安装新版不会主动清除已有本地数据。
- 升级、换设备或卸载前，请先在“设置 → 数据与备份”导出完整备份。
- 完整备份可恢复知识库、设置、学习计划、进度及已支持的学习记录。

## 安装说明

Windows 安装器支持选择安装目录；如果系统缺少 WebView2，安装时可能需要联网补充运行环境。

Android 版最低支持 Android 7.0。首次安装 APK 时，手机可能会要求允许当前文件管理器或浏览器安装未知来源应用。

## 安全校验

每个版本都提供 `SHA256SUMS.txt`。可用 SHA-256 校验下载文件是否完整。
